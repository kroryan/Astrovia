## Full description (EN)
Astrovia is a free, open-source sky atlas for Android. Pan and zoom across the whole sky using HiPS
surveys (DSS2, 2MASS, WISE, GALEX…), identify objects with Simbad, overlay VizieR catalogs
(Gaia, Tycho-2, 2MASS, SDSS…), place markers, measure angular distances and download surveys
for offline use.

• No ads, no accounts, no tracking
• Offline mode with downloaded surveys
• Coordinate grid, brightness / contrast / invert
• Source code available under GNU GPL v3

Astrovia is an independent project based on the Aladin Sky Atlas developed by the Centre de Données
astronomiques de Strasbourg (CDS). It is NOT affiliated with or endorsed by the CDS. This Android
adaptation was created with the help of AI tools.
